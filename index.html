Complete Claude Cowork Setup
One-time setup. Then Claude does everything automatically — detecting new subscribers, sending welcome emails with today's digest, and running the daily job scan every morning.
01

Create a Google Form with 2 fields

Go to forms.google.com → New Form → Add: Full Name (Short answer) + Email Address (Short answer, set validation to email). Link responses to a Google Sheet. Copy the Form link and replace the subscribe button URL above.

02

Connect Gmail in Claude Desktop

Open Claude Desktop → Cowork tab → "+" → Connectors → Gmail → Authorize. This allows Claude to send emails on your behalf. Already connected ✅ (Gmail is in your connected apps).

03

Connect Google Drive (to read the Sheet)

In Cowork → "+" → Connectors → Google Drive → Authorize. This lets Claude read the Google Sheet where Form responses land. Share the Sheet with Claude or place it in an accessible Drive folder.

04

Create the Scheduled Task — type /schedule in Cowork
